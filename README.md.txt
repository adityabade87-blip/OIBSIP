Google Play Store Analysis

Project Overview

This project analyzes Google Play Store applications and user reviews to understand app categories, ratings, installs, pricing, app sizes, and user sentiment.

Objectives

- Analyze app categories and ratings.
- Compare free and paid applications.
- Explore app size and installation patterns.
- Analyze positive, negative, and neutral user reviews.
- Create visualizations to communicate findings.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

Dataset

The project uses two datasets from Kaggle:

- Google Play Store Apps
- Google Play Store User Reviews

Project Workflow

1. Load the datasets.
2. Inspect and clean the data.
3. Handle missing values and duplicate records.
4. Analyze app categories, ratings, installs, and prices.
5. Explore user review sentiments.
6. Create static and interactive visualizations.
7. Summarize key insights and recommendations.

Key Analysis

- App category distribution
- Average app ratings
- Free vs paid apps
- App size vs installs
- User review sentiment distribution
- Category-wise sentiment analysis

Conclusion

This project uses data analysis and visualization to explore Google Play Store apps and user feedback. The results can help identify app market patterns and areas for improving user experience.
